This document is intended to give a high-level overview of how the TUEG-VLM project will be structured in its finality.

* /scratch
** /ollama
various ollama installs
** /huggingface
various huggingface installs
** /TUEG-VLM-prediction
*** /train
*** /eval
**** /runs
***** /run-<date>-<time>
****** /logs
****** /results
****** tasks.json
****** status.csv
keeps track of each completed run, failed, run, reasons why, which model + dataset, etc.
****** summary.csv
generated by summarize.py, does not exist by default
****** rank.csv
generated by summarize.py, does not exist by default
****** config.yml
copy of the config.yml that was used to create this run
**** /scripts
***** eval.py
***** download.sh
***** structure.py
